StayCheck privacy policy

Last updated: 30 August 2026

StayCheck is a Chrome extension that shows Google Maps ratings and review excerpts next to a hotel listing you already opened on Booking.com, Agoda, or Expedia. It is a comparison aid. It does not rank hotels, create an account, or sell data.

Data StayCheck reads on the page

When you open a supported hotel property page (not a search-results page), the extension reads the hotel name and address from structured data or visible page text so it can search Google Maps for that property.

Data sent to StayCheck’s server

The extension sends the hotel name and address, plus an anonymous installation identifier, to StayCheck’s Cloudflare Worker at staycheck-api.msannan121.workers.dev. That server calls Google Places API (New) and returns a match, candidate listings, rating, review count, Maps links, and up to five Google review excerpts.

The server does not store hotel names, addresses, or review text. It stores only anonymous usage counters (installation/month, salted IP/day, and a global daily cap) so Google Maps costs stay bounded.

Data kept on your device

Chrome local storage on your profile may keep:

  • an anonymous installation ID used for monthly usage limits
  • Google Place IDs you confirm when automatic matching is uncertain
  • optional diagnostic events (event name, short error text, timestamp, page path) until you copy or clear them

Diagnostic details stay on the device unless you choose Help diagnose an issue → Copy details.

What StayCheck does not do

  • no accounts, analytics SDKs, advertising, or payment processing
  • no scanning of search-result pages or browsing history
  • no sale or brokerage of user data
  • no use of Google review text to train models or build a review warehouse

Google APIs

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements. Review excerpts are Google Maps content. StayCheck displays Google attribution, author names, author photos when provided, author profile links, and links to the original Maps listing.

Contact
